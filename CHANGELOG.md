# Changelog

## 0.7.0

- Added movie subtitle generation mode for local media files.
- Added translation-only and bilingual `.srt` export.
- Added desktop file picker and subtitle save dialog.
- Added `/v1/subtitles` backend endpoint for timestamped full-file transcription and translation.
- Documented the difference between soft-subtitle replacement and hard-subtitle removal.

## 0.6.0

- Added English, Simplified Chinese, Japanese, Korean, French and German UI switching.
- Added GPU, VRAM, RAM and CPU detection with model recommendations.
- Added source-only, translation-only and bilingual subtitle modes.
- Upgraded default GPU ASR to `large-v3-turbo`.
- Added Simplified Chinese normalization and OpenAI-compatible translation endpoints.
- Added local translation validation and timing metrics.
